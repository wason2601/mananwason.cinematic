# Manan Wason · Portfolio (cinematic edition)

Same multi-page portfolio as `mananwason.portfolio`, opening with a cinematic intro:
rapid comic-panel flips built from real results ($20M, $3.6M, +26%, +37%, +15%), company logos,
launch sketches and the avatar, slamming into a "MANAN WASON · PRODUCT MANAGER" title card.

- Plays once per browser session; **Skip**, **Esc** or a click ends it; **Replay intro** in the footer.
- **Sound on** replays it with synthesised whooshes and a low boom (no audio files).
- Skipped entirely for visitors who prefer reduced motion.
- No libraries: native Web Animations API + Web Audio.

Live at https://wason2601.github.io/mananwason.cinematic/ once Pages is enabled
(Settings → Pages → Deploy from a branch → `main` / root).
